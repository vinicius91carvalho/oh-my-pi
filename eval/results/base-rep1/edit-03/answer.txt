```js
export function formatCents(cents, code) {
  const sign = cents < 0 ? "-" : "";
  const abs = Math.abs(cents);
  return `${sign}${Math.floor(abs / 100)}.${String(abs % 100).padStart(2, "0")} ${code.toUpperCase()}`;
}
```
Integer-only arithmetic (no float), code uppercased per the ISO-4217 rule. `formatCents(1234, "usd")` → `"12.34 USD"`.
