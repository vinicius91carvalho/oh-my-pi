- **Root cause:** `postingIdentity` recognized only the hosts `boards.greenhouse.io` and `boards-api.greenhouse.io`. Greenhouse's current job board host is `job-boards.greenhouse.io`, so the function returned `null` for URLs like `https://job-boards.greenhouse.io/mozilla/jobs/8089088`. The pipeline's `checkPostingLive` treats "no identity" as "I could not ask", so it answered `unknown` and never called `fetch`. The adapters package had already learned the `job-` prefix in `parseAtsBoard`; the core's copy of the host regex (a documented duplication, since core sits below adapters) had drifted.
- **Fix:** host regex changed to `/(^|\.)job-?boards(-api)?\.greenhouse\.io$/`, which matches `boards`, `job-boards`, and `boards-api` in one pattern, plus a comment warning that a missed host here reads as a silent `unknown`.
